# 🎵 Memory and Musical Training Analysis

## Overview

This project investigates the relationship between musical training and different types of memory performance using a publicly available cognitive science dataset of 1,438 participants.

The project follows a complete data science workflow, including data exploration, SQL analysis, statistical analysis, feature engineering, and machine learning.

---

## Research Question

How is musical training associated with verbal, spatial, and auditory memory performance in young adults?

---

## Objectives

- Explore the dataset and understand the variables
- Analyze different types of memory performance
- Investigate relationships between musical training and memory
- Build predictive machine learning models
- Interpret the most important predictors of memory performance

## Dataset

This project uses an open cognitive science dataset containing measures of:

- Musical training
- Personality
- Demographics
- Working memory
- Spatial memory
- Melody memory
- Intelligence

The dataset was originally collected for research comparing musicians and non-musicians.
